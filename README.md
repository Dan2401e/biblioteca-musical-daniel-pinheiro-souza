## 📌 Sobre o projeto

A **Biblioteca Musical** é um projeto de desenvolvimento web que tem como objetivo criar um sistema para gerenciamento e organização de músicas e artistas.

A aplicação está sendo construída com foco em uma interface intuitiva, organizada e funcional, permitindo que o usuário navegue entre diferentes áreas do sistema e tenha acesso às principais funcionalidades de gerenciamento musical.

Atualmente, o projeto está em sua etapa de desenvolvimento frontend, utilizando HTML5 e CSS3 para estruturar e estilizar as páginas.

Futuramente, a aplicação receberá uma integração com banco de dados e backend, permitindo o armazenamento, processamento e gerenciamento dinâmico das informações.

## 🎯 Objetivos

- Desenvolver uma plataforma de gerenciamento musical.
- Organizar informações de artistas e músicas.
- Criar uma interface simples e intuitiva.
- Implementar funcionalidades de cadastro, consulta e gerenciamento.
- Desenvolver uma estrutura preparada para futuras integrações com banco de dados e backend.

## ✨ Funcionalidades

O projeto conta atualmente com as seguintes páginas:

| Página | Descrição |
|---|---|
| Login | Interface de acesso ao sistema. |
| Menu principal | Área inicial com acesso às funcionalidades. |
| Cadastro de artistas | Interface para cadastrar e gerenciar artistas. |
| Cadastro de músicas | Interface para adicionar músicas ao sistema. |
| Biblioteca musical | Página destinada à visualização e filtragem das músicas. |

## 🛠️ Tecnologias utilizadas

As tecnologias utilizadas na etapa atual do desenvolvimento são:

- **HTML5:** estruturação e organização das páginas.
- **CSS3:** estilização, identidade visual e organização dos elementos.

### Tecnologias previstas para as próximas etapas

- **PHP:** desenvolvimento do backend e processamento das informações.
- **MySQL:** gerenciamento e armazenamento dos dados.
- **Integração Frontend e Backend:** comunicação entre a interface e o servidor.

## 🚀 Como executar o projeto

Para visualizar a versão atual da aplicação:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `login.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server do VS Code.
5. Navegue pelas páginas e conheça as funcionalidades disponíveis.

### Clonar o repositório

